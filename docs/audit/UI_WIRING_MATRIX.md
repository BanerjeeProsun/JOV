## High-Risk UI Wiring Flags Identified

1. **Missing Authentication Forms & Route Guards**: There are no Sign In, Register, Forgot Password, or Account Profile screens in the UI. Anyone navigating to `/` enters the workspace immediately with full access to whichever candidate profile is active.
2. **Settings In-Memory Only**: Saving settings via `PATCH /api/v1/settings` updates Python memory (`settings.SUITABILITY_FLOOR = ...`), but does not write to a database settings table. Server restart reverts settings to defaults.
3. **Job Discovery Lacks Geo Filters**: The search box in `JobDiscoveryScreen.tsx` only filters locally loaded job cards by title/company/description text. There is no country, state, or city filter, and no API pushdown.
4. **Hard-coded Candidate Fallback**: If no candidate exists in the database, `web/src/api/client.ts:75` calls `createCandidate` with hard-coded `display_name: 'My Profile'`.
