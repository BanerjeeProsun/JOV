## 2. Hardening Requirements for Milestone 2

### Clean Provider Abstraction (`src/jovsi/services/llm.py`)
```python
class LLMProvider(ABC):
    @abstractmethod
    async def generate_structured(self, task: str, schema: Type[BaseModel], prompt: str) -> BaseModel:
        ...
```
- **Supported Providers**: Google Gemini adapter via direct official HTTPS REST API (`generativelanguage.googleapis.com/v1beta/models/{model}:generateContent`) with JSON schema enforcement.
- **Error Handling**: Explicit exceptions: `NotConfiguredError`, `AuthFailedError`, `RateLimitedError`, `InvalidOutputError`, `TimeoutError`.
- **Bounded Retry**: 3 attempts with exponential backoff and jitter for transient 429 / 503 errors.
- **Timeouts**: Strict 15-second timeout on outbound LLM calls.
- **Deterministic Fallbacks**: Every task (resume tailoring, cover letters, requirement parsing) must provide a rule-based fallback and flag its result with `source: "llm" | "fallback"`.

### Health & Diagnostic Telemetry
- Implement `/api/v1/health/llm`:
  ```json
  {
    "provider": "gemini",
    "model": "gemini-2.5-flash",
    "configured": true,
    "last_check_status": "ok",
    "source_mode": "llm"
  }
  ```
  *(Never returns or leaks the API key value)*.
- Minimal 1-token real check action only when a key is explicitly configured.

### Untrusted Input & Factual Grounding Safety
- All external text (job descriptions, resumes, fetched HTML) is treated as untrusted data, sanitized via `UntrustedInputSanitizer`, wrapped in XML delimiters (`<data>...</data>`), and instructed not to follow prompt instructions inside data blocks.
- **Factual Grounding Validator**: Every bullet generated by the LLM must have its claimed skills/experiences validated against active verified candidate facts. Any unverified claim causes rejection and fallback to deterministic templates.
